## 2. `/etc` 디렉터리

`/etc`는 Linux 시스템의 **설정 파일과 시스템 전반의 구성 정보**가 저장되는 디렉터리이다.

실습 과정에서 `/etc`의 파일과 디렉터리 목록을 확인하고, 각 항목의 권한·소유자·그룹·크기 등의 정보를 살펴보았다.

예시:

```bash
ls -l /etc
```

출력 결과를 파일로 저장하여 학습 자료로 남겼다.

## 3. 파일 및 디렉터리 관리

오늘 실습에서는 날짜별 학습 폴더 안에 파일과 디렉터리를 직접 만들면서 Linux의 파일 시스템 구조를 확인했다.

- 파일 생성 및 내용 확인
- 디렉터리 생성
- 디렉터리 구조 확인
- 파일을 별도의 학습 자료로 저장

특히 `new-dir` 디렉터리 안에 `/etc` 목록을 저장한 `etc-files` 파일을 만들어 시스템 디렉터리의 실제 구성을 확인했다.

## 4. 압축/아카이브 실습

`tar-test`, `tgz-test` 디렉터리를 생성하여 `tar` 및 `tar.gz(tgz)` 형식의 아카이브 실습을 진행했다.

### 주요 명령어

```bash
# tar.gz 형식으로 압축
 tar -czvf practice_exam.tar.gz practice_exam

# tar.gz 압축 해제
 tar -xzvf ~/practice_exam.tar.gz -C /tmp/exam_restore
```

- `c`: 새 아카이브 생성(create)
- `x`: 아카이브 해제(extract)
- `z`: gzip 사용
- `v`: 처리 과정 출력(verbose)
- `f`: 아카이브 파일 지정(file)

실습에서는 `practice_exam` 디렉터리 안에 `apple`, `banana`, `orange` 파일을 만든 후 `tar.gz`로 묶고, `/tmp/exam_restore`에 다시 압축 해제하여 파일이 정상적으로 복원되는지 확인했다.

## 5. 디스크 사용량 확인

압축 및 파일 관리 실습과 함께 시스템의 디스크 사용량도 확인했다.

### `df`

파일 시스템별 전체 용량, 사용량, 남은 용량 등을 확인한다.

```bash
df
```

### `du`

현재 디렉터리나 특정 디렉터리가 사용하고 있는 디스크 공간을 확인한다.

```bash
du
```

`df`는 **파일 시스템 전체의 디스크 사용량**을 확인할 때 사용하고, `du`는 **특정 디렉터리나 파일이 차지하는 공간**을 확인할 때 사용한다.

## 6. 오늘 실습 흐름

```text
디렉터리 생성
    ↓
파일 생성(touch)
    ↓
tar.gz 압축
    ↓
압축 파일 생성 확인
    ↓
/tmp에 압축 해제
    ↓
ls -al로 복원 파일 확인
    ↓
df / du로 디스크 사용량 확인
```

## 7. 오늘 학습 핵심 정리

> Linux에서는 파일과 디렉터리를 생성하고 관리하는 것뿐만 아니라, 여러 파일을 하나의 아카이브로 묶어 보관하거나 다른 위치에 복원하는 작업도 중요하다.
>
> `tar` 명령어의 옵션을 조합하여 `tar.gz` 파일을 만들고 압축을 해제하는 과정을 직접 실습했으며, `df`와 `du`를 이용해 디스크 사용량을 확인하는 방법도 익혔다.
