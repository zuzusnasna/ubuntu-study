# 2026-09-15 Linux 학습 정리

## 1. 오늘 학습 주제

- Linux 파일 및 디렉터리 관리
- 시스템 설정 디렉터리 `/etc` 확인
- 파일과 디렉터리 생성 및 구조 확인
- 압축/아카이브 실습을 위한 디렉터리 구성

## 2. `/etc` 디렉터리

`/etc`는 Linux 시스템의 **설정 파일과 시스템 전반의 구성 정보**가 저장되는 디렉터리이다.

실습 과정에서 `/etc`의 파일과 디렉터리 목록을 확인하고, 각 항목의 권한·소유자·그룹·크기 등의 정보를 살펴보았다.

예시:

```bash
ls -l /etc
```

출력 결과를 파일로 저장하여 학습 자료로 남겼다.

## 3. 파일 및 디렉터리 관리

오늘 실습에서는 날짜별 학습 폴더 안에 파일과 디렉터리를 직접 만들면서 Linux의 파일 시스템 구조를 확인했다.

- 파일 생성 및 내용 확인
- 디렉터리 생성
- 디렉터리 구조 확인
- 파일을 별도의 학습 자료로 저장

특히 `new-dir` 디렉터리 안에 `/etc` 목록을 저장한 `etc-files` 파일을 만들어 시스템 디렉터리의 실제 구성을 확인했다.

## 4. 압축/아카이브 실습 준비

`tar-test`, `tgz-test` 디렉터리를 생성하여 `tar` 및 `tar.gz(tgz)` 형식의 아카이브 실습을 진행할 수 있도록 환경을 구성했다.

- `tar`: 여러 파일과 디렉터리를 하나의 아카이브로 묶는 용도
- `tar.gz` / `tgz`: tar 아카이브를 gzip으로 압축한 형태

## 5. 파일 내용 다루기

`lyrics` 파일을 생성하여 텍스트 파일을 직접 만들고 내용을 저장하는 실습도 진행했다.

이를 통해 Linux에서 파일을 생성하고 내용을 기록한 뒤 Git을 이용해 학습 기록으로 관리하는 흐름을 확인했다.

## 6. 오늘 학습 핵심 정리

> Linux에서는 파일과 디렉터리를 단순히 사용하는 것뿐만 아니라, 시스템 설정 파일이 위치한 `/etc`와 같은 주요 디렉터리의 역할을 이해하고 직접 파일 구조를 확인하는 것이 중요하다.
>
> 또한 파일/디렉터리 생성 → 내용 확인 → 아카이브 구성 → Git으로 학습 기록 관리까지 연결하여 Linux 환경에서의 기본적인 파일 관리 흐름을 익혔다.
