| 날짜 | 주제 | 주요 키워드 | 학습 내용 요약 |
|---|---|---|---|
| [2026-09-11](./2026-09-11/) | Linux 기초 / 파일 시스템 | `Terminal` `Shell` `Bash` `Shell Script` `ls` `cd` `pwd` `mkdir` `rmdir` `절대 경로` `상대 경로` | 터미널과 셸, 셸 스크립트, Linux 파일 시스템 구조, 경로와 디렉터리 관리 학습 |

---

## 📝 날짜별 기록 방법

앞으로 학습한 날짜가 생길 때마다 위 표에 한 줄씩 추가합니다.

- **날짜** → 해당 날짜 폴더로 바로 이동
- **주제** → 그날 학습한 큰 주제
- **주요 키워드** → 명령어, 개념, 기술 등 핵심 키워드
- **학습 내용 요약** → 그날 학습한 내용을 짧게 정리

### 작성 예시

| 날짜 | 주제 | 주요 키워드 | 학습 내용 요약 |
|---|---|---|---|
| `2026-09-12` | 사용자 / 권한 | `user` `group` `chmod` `chown` `sudo` | Linux 사용자와 그룹, 파일 및 디렉터리 권한 관리 학습 |

> 학습하지 않은 내용은 미리 추가하지 않고, **실제로 공부한 날짜에 맞춰 하나씩 추가**합니다.
