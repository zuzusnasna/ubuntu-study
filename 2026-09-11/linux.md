# 2026-09-11 Linux 학습

## 3.1 터미널과 셸

### 터미널(Terminal)

터미널은 **사용자와 컴퓨터가 상호작용하기 위한 매체**이다.

사용자는 터미널을 통해 운영체제에 명령어를 입력하고, 컴퓨터의 실행 결과를 확인할 수 있다.

### 셸(Shell)

셸은 사용자가 입력한 명령어를 해석하고 운영체제가 해당 작업을 수행할 수 있도록 전달하는 프로그램이다.

즉,

```text
사용자
  ↓
터미널
  ↓
셸
  ↓
운영체제
```

와 같은 관계로 이해할 수 있다.

### 3.1.3 터미널과 셸의 관계

* **터미널** → 사용자가 컴퓨터와 상호작용할 수 있도록 해주는 환경
* **셸** → 터미널에서 입력한 명령어를 해석하고 실행하는 프로그램

컴퓨터가 부팅되면 운영체제는 터미널을 통해 사용자에게 정보를 보여주고, 사용자가 명령을 입력할 수 있는 환경을 제공한다.

## 3.2 셸 스크립트

### 셸 스크립트(Shell Script)

셸에서 실행할 수 있는 여러 명령어를 **하나의 파일에 작성해 놓은 것**이다.

여러 명령어를 하나씩 직접 입력하지 않고 파일에 작성한 뒤 한 번에 실행할 수 있다.

예:

```bash
echo "Hello"
pwd
ls
```

위 명령어들을 `hello.sh`와 같은 파일에 작성하면 셸 스크립트로 실행할 수 있다.

### 셸 스크립트의 장점

* 여러 명령어를 한 번에 실행할 수 있다.
* 반복적인 작업을 자동화할 수 있다.
* 서버 배포 및 관리 작업에 활용할 수 있다.

---

## 3.2.1 셸 스크립트 작성 실습

기본적인 실습 과정:

1. Ubuntu에서 터미널 실행
2. 터미널에서 명령어 입력
3. `echo` 명령어 실행
4. `nano` 편집기 실행
5. `hello.sh` 파일 작성
6. 셸 스크립트 저장
7. `hello.sh` 실행
8. 실행 결과 확인

### echo

문자열이나 값을 터미널에 출력할 때 사용한다.

```bash
echo "Hello Ubuntu"
```

실행 결과:

```text
Hello Ubuntu
```

## 3.3 기본 명령어

### 3.3.1 명령어 형식

Linux 명령어는 기본적으로 다음과 같은 형태로 사용할 수 있다.

```bash
명령어 옵션 대상
```

예:

```bash
ls -l
```

### ls

현재 디렉터리의 파일과 디렉터리를 확인한다.

```bash
ls
```

### ls -l

파일과 디렉터리의 정보를 자세하게 출력한다.

```bash
ls -l
```

파일의 권한, 소유자, 크기, 수정 시간 등의 정보를 확인할 수 있다.

### ls -al

숨김 파일까지 포함하여 자세한 정보를 출력한다.

```bash
ls -al
```

* `-l` → 자세한 정보 출력
* `-a` → 숨김 파일 포함

## cd

디렉터리를 이동할 때 사용하는 명령어이다.

```bash
cd 디렉터리명
```

홈 디렉터리로 이동하려면:

```bash
cd ~
```

또는 단순히:

```bash
cd
```

사용할 수 있다.

현재 위치는 다음 명령어로 확인할 수 있다.

```bash
pwd
```

## /etc/passwd

Linux에서 사용자 계정 정보를 확인할 수 있는 파일이다.

```text
/etc/passwd
```

사용자 계정과 관련된 기본적인 정보가 저장되어 있다.

확인:

```bash
cat /etc/passwd
```

> 참고: `/etc/passwd`는 엄밀히 말하면 '환경변수나 설정이 저장된 디렉터리'가 아니라 **사용자 계정 정보를 저장하는 파일**이다.

## nano

터미널에서 사용할 수 있는 텍스트 편집기이다.

파일을 열거나 파일이 존재하지 않을 경우 새로 만들 수 있다.

```bash
nano 파일명
```

예:

```bash
nano hello.sh
```

### nano 주요 단축키

```text
Ctrl + X  → 종료
Ctrl + O  → 저장
```

`Ctrl`을 누른 상태에서 해당 키를 누른다.

## 오늘의 핵심 정리

```text
터미널
→ 사용자와 컴퓨터가 상호작용하는 환경

셸
→ 사용자가 입력한 명령어를 해석하고 실행

셸 스크립트
→ 여러 셸 명령어를 파일에 작성하여 한 번에 실행

ls
→ 파일/디렉터리 목록 확인

ls -l
→ 자세한 정보 확인

ls -al
→ 숨김 파일을 포함한 자세한 정보 확인

cd
→ 디렉터리 이동

pwd
→ 현재 디렉터리 확인

nano
→ 터미널 텍스트 편집기

/etc/passwd
→ 사용자 계정 정보가 저장된 파일
```
