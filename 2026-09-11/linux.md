# Linux 학습 정리

## 3.1 터미널과 셸

### 터미널(Terminal)

터미널은 사용자가 컴퓨터와 상호작용할 수 있도록 해주는 프로그램입니다.

사용자가 키보드로 명령어를 입력하면 터미널을 통해 셸에 전달됩니다.

### 셸(Shell)

셸은 사용자가 입력한 명령어를 해석하여 운영체제에 전달하는 프로그램입니다.

대표적인 셸로 **Bash**가 있습니다.

### 터미널과 셸의 관계

```text
사용자
  ↓
터미널
  ↓
셸(Bash)
  ↓
운영체제
```

---

## 3.2 셸 스크립트

셸 스크립트(Shell Script)는 여러 개의 셸 명령어를 하나의 파일에 작성하여 실행할 수 있도록 만든 파일입니다.

반복적으로 실행해야 하는 명령어를 하나의 스크립트로 만들어 자동화할 수 있습니다.

### 셸 스크립트의 장점

* 여러 명령어를 한 번에 실행할 수 있다.
* 반복 작업을 자동화할 수 있다.
* 서버 관리 및 배포 작업에 활용할 수 있다.
* 작업 과정을 파일로 저장하여 재사용할 수 있다.

---

## 3.2.1 셸 스크립트 실습

### 터미널 실행

Ubuntu에서 터미널을 실행합니다.

### `echo` 명령어

`echo`는 문자열을 터미널에 출력하는 명령어입니다.

```bash
echo "Hello Linux"
```

### `nano` 편집기

파일을 생성하거나 수정할 때 `nano`를 사용할 수 있습니다.

```bash
nano hello.sh
```

파일에 다음 내용을 작성합니다.

```bash
#!/bin/bash

echo "Hello Linux"
```

저장 후 실행합니다.

```bash
./hello.sh
```

실행 권한이 없다면 다음 명령어를 사용합니다.

```bash
chmod +x hello.sh
```

다시 실행합니다.

```bash
./hello.sh
```

## 3.3 기본 명령어

### `ls`

현재 디렉터리의 파일과 디렉터리를 확인합니다.

```bash
ls
```

### `ls -l`

파일과 디렉터리의 상세 정보를 확인합니다.

```bash
ls -l
```

### `ls -al`

숨김 파일을 포함한 모든 파일과 디렉터리의 상세 정보를 확인합니다.

```bash
ls -al
```

---

## `cd`

디렉터리를 이동할 때 사용하는 명령어입니다.

```bash
cd 디렉터리명
```

### 홈 디렉터리로 이동

```bash
cd ~
```

또는

```bash
cd
```

### `pwd`

현재 작업 중인 디렉터리의 위치를 확인합니다.

```bash
pwd
```

---

## `/etc/passwd`

`/etc/passwd`는 리눅스 시스템에 등록된 **사용자 계정 정보를 저장하는 파일**입니다.

파일의 내용을 확인하려면 다음 명령어를 사용할 수 있습니다.

```bash
cat /etc/passwd
```

# 4. 파일과 디렉터리

## 4.2 리눅스의 파일 계층 구조

리눅스는 모든 파일과 디렉터리를 **계층 구조**로 관리합니다.

윈도우에서는 `C:`, `D:`와 같은 드라이브를 기준으로 파일 시스템이 구성되지만, 리눅스에서는 **루트 디렉터리(`/`)**를 최상위로 하여 모든 파일과 디렉터리가 연결됩니다.

디스크나 다른 파일 시스템을 리눅스의 디렉터리 구조에 연결하는 것을 **마운트(mount)**라고 합니다.

---

## 4.3 파일의 종류

리눅스에서는 파일의 종류를 파일 앞에 표시되는 문자로 구분할 수 있습니다.

### 파일 종류별 표시 문자

| 표시 문자 | 파일 종류    |
| ----- | -------- |
| `-`   | 일반 파일    |
| `d`   | 디렉터리     |
| `l`   | 심볼릭 링크   |
| `c`   | 문자 장치 파일 |
| `b`   | 블록 장치 파일 |
| `p`   | 파이프      |
| `s`   | 소켓       |

`ls -l` 명령어를 사용하면 파일 종류를 확인할 수 있습니다.

```bash
ls -l
```

예:

```text
-rw-r--r--  일반 파일
drwxr-xr-x  디렉터리
lrwxrwxrwx  심볼릭 링크
```

출력의 **첫 번째 문자**를 확인하면 파일의 종류를 알 수 있습니다.

## 4.4 디렉터리

### 디렉터리(directory)

디렉터리는 파일 시스템을 **계층화하여 관리하기 위한 도구**입니다.

윈도우의 폴더와 비슷한 개념입니다.

---

## 4.4.1 루트 디렉터리

**루트 디렉터리(root directory)**는 파일 시스템의 최상단에 위치하는 디렉터리입니다.

리눅스에서는 `/`로 표시합니다.

```text
/
├── bin
├── boot
├── dev
├── etc
├── home
├── lib
├── media
├── mnt
├── opt
├── root
├── sbin
├── tmp
├── usr
└── var
```

### 루트 디렉터리 하위의 주요 디렉터리

| 디렉터리    | 설명               |
| ------- | ---------------- |
| `/`     | 루트 디렉터리          |
| `/home` | 일반 사용자의 홈 디렉터리   |
| `/root` | root 사용자의 홈 디렉터리 |
| `/etc`  | 시스템 설정 파일        |
| `/bin`  | 기본 명령어           |
| `/usr`  | 사용자 프로그램 및 관련 파일 |
| `/var`  | 로그 등 계속 변경되는 데이터 |
| `/tmp`  | 임시 파일            |
| `/dev`  | 장치 파일            |
| `/boot` | 부팅에 필요한 파일       |

---

## 4.4.2 현재 작업 디렉터리

**현재 작업 디렉터리**는 현재 Bash가 작업을 수행하고 있는 디렉터리입니다.

현재 위치는 `pwd` 명령어로 확인할 수 있습니다.

```bash
pwd
```

예:

```text
/home/jusang
```

---

## 4.4.3 홈 디렉터리

**홈 디렉터리(home directory)**는 리눅스에 사용자를 추가할 때 사용자별로 할당되는 디렉터리입니다.

일반적으로 `/home/사용자명` 형태로 만들어집니다.

예:

```text
/home/jusang
```

`~` 기호는 현재 사용자의 홈 디렉터리를 의미합니다.

```bash
cd ~
```

---

## 4.4.4 상대 경로와 절대 경로

**경로(path)**는 파일이나 디렉터리의 위치 정보를 나타내는 것입니다.

### 상대 경로

**현재 작업 디렉터리를 기준으로** 파일이나 디렉터리의 위치를 나타내는 방법입니다.

예:

```bash
cd ubuntu-study
```

현재 위치에 `ubuntu-study` 디렉터리가 있다면 현재 작업 디렉터리를 기준으로 이동합니다.

### 절대 경로

**루트 디렉터리(`/`)를 기준으로** 파일이나 디렉터리의 위치를 나타내는 방법입니다.

예:

```bash
cd /home/jusang/ubuntu-study
```

어떤 디렉터리에 있더라도 `/`부터 시작하는 전체 경로를 사용하여 이동할 수 있습니다.

# 4.5 실습: 파일과 디렉터리 다루기

## 4.5.1 디렉터리 생성하기

디렉터리를 생성할 때는 `mkdir` 명령어를 사용합니다.

`mkdir`은 **make directory**의 약자입니다.

```bash
mkdir 디렉터리명
```

### 실습 순서

#### 1. `ls` 명령어로 현재 디렉터리 확인

```bash
ls
```

#### 2. `animals` 디렉터리 생성

```bash
mkdir animals
```

`animals` 디렉터리 안에 `dog`, `cat`, `cow` 디렉터리를 생성합니다.

```bash
mkdir animals/dog
mkdir animals/cat
mkdir animals/cow
```

#### 3. `snake` 디렉터리 생성

```bash
mkdir animals/snake
```

#### 4. `-p` 옵션 없이 하위 디렉터리 생성

존재하지 않는 `fruits` 디렉터리 아래에 `apple` 디렉터리를 생성합니다.

```bash
mkdir fruits/apple
```

`fruits` 디렉터리가 존재하지 않기 때문에 오류가 발생합니다.

#### 5. `-p` 옵션을 사용하여 생성

```bash
mkdir -p fruits/apple
```

`-p` 옵션을 사용하면 필요한 상위 디렉터리까지 함께 생성할 수 있습니다.

결과:

```text
fruits
└── apple
```

#### 6. `-p` 옵션으로 이미 존재하는 디렉터리를 다시 생성

```bash
mkdir -p fruits/apple
```

이미 존재하는 디렉터리라도 `-p` 옵션을 사용하면 오류 없이 실행할 수 있습니다.

---

## 4.5.2 디렉터리 삭제하기

디렉터리를 삭제할 때는 `rmdir` 명령어를 사용합니다.

`rmdir`은 **remove directory**의 약자입니다.

단, `rmdir`은 **비어 있는 디렉터리만 삭제할 수 있습니다.**

### 실습 순서

#### 1. `ls` 명령어로 디렉터리 확인

```bash
ls
```

#### 2. `animals`의 하위 디렉터리 확인

```bash
ls animals
```

#### 3. `cat` 디렉터리 삭제

```bash
rmdir animals/cat
```

#### 4. 남아 있는 디렉터리 3개 한꺼번에 삭제

```bash
rmdir animals/dog animals/cow animals/snake
```

#### 5. `animals` 디렉터리 삭제

```bash
rmdir animals
```

#### 6. `fruits` 디렉터리 확인

```bash
ls
```

#### 7. `fruits` 디렉터리 삭제 시도

```bash
rmdir fruits
```

`fruits` 안에 `apple` 디렉터리가 존재하기 때문에 삭제되지 않습니다.

#### 8. `-p` 옵션을 사용하여 `fruits` 디렉터리 삭제

```bash
rmdir -p fruits/apple
```

`-p` 옵션을 사용하면 지정한 디렉터리를 삭제한 뒤, 비어 있는 상위 디렉터리도 함께 삭제할 수 있습니다.

# 핵심 정리

* 터미널은 사용자와 컴퓨터가 상호작용할 수 있도록 해준다.
* 셸은 사용자가 입력한 명령어를 해석하여 운영체제에 전달한다.
* 셸 스크립트는 여러 명령어를 하나의 파일로 만들어 자동화할 수 있다.
* `ls`는 파일과 디렉터리를 확인한다.
* `cd`는 디렉터리를 이동한다.
* `pwd`는 현재 작업 디렉터리를 확인한다.
* `/etc/passwd`는 사용자 계정 정보를 저장한다.
* 리눅스 파일 시스템의 최상위 디렉터리는 `/`이다.
* 디렉터리는 파일 시스템을 계층적으로 관리하기 위한 도구이다.
* `~`는 현재 사용자의 홈 디렉터리를 의미한다.
* 상대 경로는 현재 작업 디렉터리를 기준으로 한다.
* 절대 경로는 루트 디렉터리(`/`)를 기준으로 한다.
* `mkdir`은 디렉터리를 생성한다.
* `mkdir -p`는 필요한 상위 디렉터리까지 함께 생성한다.
* `rmdir`은 비어 있는 디렉터리를 삭제한다.
* `rmdir -p`는 비어 있는 상위 디렉터리까지 함께 삭제할 수 있다.
* `ls -l`의 첫 번째 문자를 통해 파일 종류를 확인할 수 있다.
