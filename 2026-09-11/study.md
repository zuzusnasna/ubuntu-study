# Linux 학습 정리

## 3.1 터미널과 셸

### 터미널(Terminal)

터미널은 사용자가 컴퓨터와 상호작용할 수 있도록 해주는 프로그램입니다.

사용자가 키보드로 명령어를 입력하면 터미널을 통해 셸에 전달됩니다.

### 셸(Shell)

셸은 사용자가 입력한 명령어를 해석하여 운영체제에 전달하는 프로그램입니다.

대표적인 셸로 **Bash**가 있습니다.

### 터미널과 셸의 관계

```text
사용자
  ↓
터미널
  ↓
셸(Bash)
  ↓
운영체제
```

---

## 3.2 셸 스크립트

셸 스크립트(Shell Script)는 여러 개의 셸 명령어를 하나의 파일에 작성하여 실행할 수 있도록 만든 파일입니다.

반복적으로 실행해야 하는 명령어를 하나의 스크립트로 만들어 자동화할 수 있습니다.

### 셸 스크립트의 장점

* 여러 명령어를 한 번에 실행할 수 있다.
* 반복 작업을 자동화할 수 있다.
* 서버 관리 및 배포 작업에 활용할 수 있다.
* 작업 과정을 파일로 저장하여 재사용할 수 있다.

### 셸 스크립트 실습

Ubuntu에서 터미널을 실행합니다.

```bash
echo "Hello Linux"
```

```bash
nano hello.sh
```

```bash
#!/bin/bash

echo "Hello Linux"
```

```bash
./hello.sh
```

실행 권한이 없다면 다음 명령어를 사용합니다.

```bash
chmod +x hello.sh
```

## 3.3 기본 명령어

### `ls`

현재 디렉터리의 파일과 디렉터리를 확인합니다.

```bash
ls
ls -l
ls -al
```

### `cd`

디렉터리를 이동할 때 사용하는 명령어입니다.

```bash
cd 디렉터리명
cd ~
```

### `pwd`

현재 작업 중인 디렉터리의 위치를 확인합니다.

```bash
pwd
```

### `/etc/passwd`

리눅스 시스템에 등록된 사용자 계정 정보를 저장하는 파일입니다.

```bash
cat /etc/passwd
```

# 4. 파일과 디렉터리

## 4.2 리눅스의 파일 계층 구조

리눅스는 모든 파일과 디렉터리를 계층 구조로 관리합니다.

최상위에는 **루트 디렉터리(`/`)**가 있으며, 디스크나 다른 파일 시스템을 디렉터리 구조에 연결하는 것을 **마운트(mount)**라고 합니다.

## 4.3 파일의 종류

| 표시 문자 | 파일 종류 |
|---|---|
| `-` | 일반 파일 |
| `d` | 디렉터리 |
| `l` | 심볼릭 링크 |
| `c` | 문자 장치 파일 |
| `b` | 블록 장치 파일 |
| `p` | 파이프 |
| `s` | 소켓 |

`ls -l` 명령어의 첫 번째 문자를 통해 파일 종류를 확인할 수 있습니다.

## 4.4 디렉터리

디렉터리는 파일 시스템을 계층화하여 관리하기 위한 도구입니다.

### 루트 디렉터리

```text
/
├── bin
├── boot
├── dev
├── etc
├── home
├── lib
├── media
├── mnt
├── opt
├── root
├── sbin
├── tmp
├── usr
└── var
```

| 디렉터리 | 설명 |
|---|---|
| `/` | 루트 디렉터리 |
| `/home` | 일반 사용자의 홈 디렉터리 |
| `/root` | root 사용자의 홈 디렉터리 |
| `/etc` | 시스템 설정 파일 |
| `/bin` | 기본 명령어 |
| `/usr` | 사용자 프로그램 및 관련 파일 |
| `/var` | 로그 등 계속 변경되는 데이터 |
| `/tmp` | 임시 파일 |
| `/dev` | 장치 파일 |
| `/boot` | 부팅에 필요한 파일 |

### 현재 작업 디렉터리

현재 작업 디렉터리는 현재 Bash가 작업을 수행하고 있는 디렉터리입니다.

```bash
pwd
```

### 홈 디렉터리

일반적으로 `/home/사용자명` 형태로 만들어지며 `~` 기호는 현재 사용자의 홈 디렉터리를 의미합니다.

```bash
cd ~
```

### 상대 경로와 절대 경로

상대 경로는 현재 작업 디렉터리를 기준으로 하며, 절대 경로는 루트 디렉터리(`/`)를 기준으로 합니다.

```bash
cd ubuntu-study
cd /home/jusang/ubuntu-study
```

# 4.5 실습: 파일과 디렉터리 다루기

## 4.5.1 디렉터리 생성하기

`mkdir`은 **make directory**의 약자로 디렉터리를 생성합니다.

```bash
mkdir animals
mkdir animals/dog
mkdir animals/cat
mkdir animals/cow
mkdir animals/snake
```

존재하지 않는 상위 디렉터리까지 함께 생성하려면 `-p` 옵션을 사용합니다.

```bash
mkdir -p fruits/apple
```

## 4.5.2 디렉터리 삭제하기

`rmdir`은 **remove directory**의 약자로 비어 있는 디렉터리를 삭제합니다.

```bash
rmdir animals/cat
rmdir animals/dog animals/cow animals/snake
rmdir animals
```

`-p` 옵션을 사용하면 지정한 디렉터리를 삭제한 뒤 비어 있는 상위 디렉터리도 함께 삭제할 수 있습니다.

```bash
rmdir -p fruits/apple
```

# 핵심 정리

* 터미널은 사용자와 컴퓨터가 상호작용할 수 있도록 해준다.
* 셸은 사용자가 입력한 명령어를 해석하여 운영체제에 전달한다.
* 셸 스크립트는 여러 명령어를 하나의 파일로 만들어 자동화할 수 있다.
* `ls`는 파일과 디렉터리를 확인한다.
* `cd`는 디렉터리를 이동한다.
* `pwd`는 현재 작업 디렉터리를 확인한다.
* `/etc/passwd`는 사용자 계정 정보를 저장한다.
* 리눅스 파일 시스템의 최상위 디렉터리는 `/`이다.
* `~`는 현재 사용자의 홈 디렉터리를 의미한다.
* 상대 경로는 현재 작업 디렉터리를 기준으로 한다.
* 절대 경로는 루트 디렉터리(`/`)를 기준으로 한다.
* `mkdir`은 디렉터리를 생성한다.
* `mkdir -p`는 필요한 상위 디렉터리까지 함께 생성한다.
* `rmdir`은 비어 있는 디렉터리를 삭제한다.
* `rmdir -p`는 비어 있는 상위 디렉터리까지 함께 삭제할 수 있다.
